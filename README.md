# Atividade 1 - Cartão de Perfil Pessoal

Projeto desenvolvido em HTML e CSS para a atividade de criação de um perfil pessoal.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — estilização
- `foto-perfil.jpg` — imagem utilizada no perfil

## Requisitos atendidos

- Título principal com o nome
- Foto
- Parágrafo de apresentação
- Lista com hobby, comida e série favorita
- Cor de fundo
- Cor do texto
- Fonte personalizada
- Borda na imagem
- Margens
- Padding
- Título centralizado
- Caixa de destaque com `border`, `background-color` e `padding`
